Detailed Description

Output structure for Addr2ComputeSurfInfo.

ADDR2_COMPUTE_SURFACE_INFO_OUTPUT

Note
Element: AddrLib unit for computing. e.g. BCn: 4x4 blocks; R32B32B32: 32bit with 3x pitch Pixel: Original pixel
