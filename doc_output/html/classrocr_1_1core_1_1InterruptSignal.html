Detailed Description

A Signal implementation using interrupts versus plain memory based. Also see base class Signal.

Breaks common/vendor separation - signals in general needs to be re-worked at the foundation level to make sense in a multi-device system. Supports only one waiter for now. KFD changes are needed to support multiple waiters and have device signaling.
