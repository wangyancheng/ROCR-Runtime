Macro for reporting fatal error conditions.

This macro optionally stops execution of the current routine after printing an error warning message to stdout, followed by the file name and line number where the macro was called. The first parameter is a condition – if it is true, nothing is done. The second pararmeter MUST be a parenthesis-enclosed list of arguments, starting with a string. This is passed to printf() or an equivalent in order to format the informational message. For example, ADDR_EXIT(0, ("test %d",3) ); prints out "test 3" followed by a second line with the file name and line number, then stops execution.
