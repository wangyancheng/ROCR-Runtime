Submit a linear copy command to the the underlying compute device's control block. The call is non blocking. The memory transfer will start after all dependent signals are satisfied. After the transfer is completed, the out signal will be decremented.

Parameters
dstMemory address of the copy destination.
srcMemory address of the copy source.
sizeSize of the data to be copied.
