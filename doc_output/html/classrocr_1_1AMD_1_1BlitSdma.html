Updates the Write Register of compute device to the end of SDMA packet written into queue buffer. The update to Write Register will be safe under multi-threaded usage scenario. Furthermore, updates to Write Register are blocking until all prior updates are completed i.e. if two threads T1 & T2 were to call release, then updates by T2 will block until T1 has completed its update (assumes T1 acquired the write address first).

Parameters
curr_indexIndex passed back from AcquireWriteAddress.
cmd_sizeCommand packet size in bytes.
