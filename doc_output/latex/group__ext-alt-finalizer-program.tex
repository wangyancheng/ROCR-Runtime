Add a HSAIL module to an existing HSAIL program. 

The HSA runtime does not perform a deep copy of the HSAIL module upon addition. Instead, it stores a pointer to the HSAIL module. The ownership of the HSAIL module belongs to the application, which must ensure that {\ttfamily module} is not released before destroying the HSAIL program.

The HSAIL module is successfully added to the HSAIL program if {\ttfamily module} is valid, if all the declarations and definitions for the same symbol are compatible, and if {\ttfamily module} specify machine model and profile that matches the HSAIL program.

\mbox{\texttt{ in}}  & {\em module} & HSAIL module. The application can add the same HSAIL module to {\ttfamily program} at most once. The HSAIL module must specify the same machine model and profile as {\ttfamily program}. If the floating-\/mode rounding mode of {\ttfamily module} is not default, then it should match that of {\ttfamily program}.\\
