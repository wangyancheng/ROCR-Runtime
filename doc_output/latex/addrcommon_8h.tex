Macro for reporting fatal error conditions. 

This macro optionally stops execution of the current routine after printing an error warning message to stdout, followed by the file name and line number where the macro was called. The first parameter is a condition -- if it is true, nothing is done. The second pararmeter MUST be a parenthesis-\/enclosed list of arguments, starting with a string. This is passed to printf() or an equivalent in order to format the informational message. For example, ADDR\+\_\+\+EXIT(0, (\char`\"{}test \%d\char`\"{},3) ); prints out \char`\"{}test 3\char`\"{} followed by a second line with the file name and line number, then stops execution. \mbox{\Hypertarget{addrcommon_8h_acac1c100428590542aca84e2886bace4}\label{addrcommon_8h_acac1c100428590542aca84e2886bace4}}
