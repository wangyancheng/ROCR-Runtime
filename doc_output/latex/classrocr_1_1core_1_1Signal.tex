\doxysubsection{Detailed Description}
An abstract base class which helps implement the public hsa\+\_\+signal\+\_\+t type (an opaque handle) and its associated APIs. At its core, signal uses a 32 or 64 bit value. This value can be waitied on or signaled atomically using specified memory ordering semantics.
