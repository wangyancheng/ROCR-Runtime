\doxysubsection{Detailed Description}
User mode queue. 

The queue structure is read-\/only and allocated by the HSA runtime, but agents can directly modify the contents of the buffer pointed by {\itshape base\+\_\+address}, or use HSA runtime APIs to access the doorbell signal.
