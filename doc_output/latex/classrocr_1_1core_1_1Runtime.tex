\doxysubsection{Detailed Description}
\mbox{\hyperlink{classrocr_1_1core_1_1Runtime}{Runtime}} class provides the following functions\+: 


\begin{DoxyItemize}
\item open and close connection to kernel driver.
\item load supported extension library (image and finalizer).
\item load tools library.
\item expose supported agents.
\item allocate and free memory.
\item memory copy and fill.
\item grant access to memory (dgpu memory pool extension).
\item maintain loader state.
\item monitor asynchronous event from agent. 
\end{DoxyItemize}
