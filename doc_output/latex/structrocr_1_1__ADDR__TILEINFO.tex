\doxysubsection{Detailed Description}
Bank/tiling parameters. On function input, these can be set as desired or left 0 for Addr\+Lib to calculate/default. On function output, these are the actual parameters used. 

\begin{DoxyNote}{Note}
Valid bank\+Width/bank\+Height value\+: 1,2,4,8. They are factors instead of pixels or bytes.
\end{DoxyNote}
The bank number remains constant across each row of the macro tile as each pipe is selected, so the number of tiles in the x direction with the same bank number will be bank\+\_\+width $\ast$ num\+\_\+pipes.
